# Mechanical 3D CAD Models (Integration & Enclosures)

[![Patent Pending](https://img.shields.io/badge/Patent-Pending-UPRP_P.457301-red.svg)]()

This directory is reserved for the 3D solid models (STEP format) demonstrating the physical integration of the T-OTP Edge Node into macro and micro zero-trust environments.

### Planned CAD Releases:
1. **`smart_label_macro.step`** (Ref: Patent Blueprint FIG. 3)
   * 3D representation of the multi-layer FPC smart label.
   * Demonstrates the physical integration on cargo containers and Data Center racks.
   
2. **`medicine_jar_cap.step`** (Ref: Patent Blueprint FIG. 2)
   * 3D cross-section of a pharmaceutical unit-level enclosure.
   * Demonstrates the micro-scale destructive bridging circuit triggered by cap rotation.

**Note:** The full `.step` mechanical integration models are currently withheld pending the final tolerance validations. They will be released under the CERN-OHL-S license in the upcoming repository update. 
For early access to mechanical dimensions for custom enclosure integration, please contact the repository maintainer.
