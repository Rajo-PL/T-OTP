# Fabrication Data (Gerber & Drill Files)
Archiwum `gerbers.zip` zawiera pliki produkcyjne RS-274X wyeksportowane dla fabryki płytek drukowanych (FPC). Projekt zoptymalizowano pod technologię Flex PCB.

**Struktura archiwum:**
* `t_otp_edge_node-F_Cu.gtl` (Top Copper - ścieżki i domena VCC_SAFE)
* `t_otp_edge_node-B_Cu.gbl` (Bottom Copper - uziemienie GND)
* `t_otp_edge_node-F_Mask.gts` (Top Solder Mask - odsłonięte pady)
* `t_otp_edge_node-B_Mask.gbs` (Bottom Solder Mask)
* `t_otp_edge_node-F_Silkscreen.gto` (Top Silkscreen - opisy i logotypy)
* `t_otp_edge_node-Edge_Cuts.gm1` (Obrys frezowania płytki)
* `t_otp_edge_node.drl` (Excellon Drill File - plik wierceń dla przelotek)
