# T-OTP Edge Node (Hardware Implementation)

[![Hardware License: CERN-OHL-S v2](https://img.shields.io/badge/Hardware-CERN--OHL--S-orange.svg)](https://cern-ohl.web.cern.ch/)
[![Patent Pending](https://img.shields.io/badge/Patent-Pending-UPRP_P.457301-red.svg)]()

Ten katalog zawiera kompletną dokumentację sprzętową (EDA/CAD) zminiaturyzowanego węzła brzegowego T-OTP, zaprojektowanego do weryfikacji integralności przestrzeni fizycznej w modelu Zero-Trust.

Projekt stanowi fizyczną implementację architektury opisanej w zgłoszeniu patentowym **P.457301**, ze szczególnym uwzględnieniem sprzętowej obsługi przerwań (NMI) zasilanej z bufora pojemnościowego.
